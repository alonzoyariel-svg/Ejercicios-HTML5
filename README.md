Colección de ejercicios introductorios de HTML5 para la asignatura **INF-4314 — Programación Web I**. Cada archivo HTML es una práctica independiente; `menu_principal.html` sirve como punto de entrada para recorrer la colección.

Los recursos de imágenes, audio y video utilizados en las prácticas se guardan en carpetas del repositorio.

## Ejecutar

Clona el repositorio y abre `menu_principal.html` o cualquier ejercicio directamente en un navegador moderno. Algunas prácticas usan recursos locales, así que conserva la estructura de carpetas al mover los archivos.

## Tecnologías

- HTML5
- Multimedia y recursos locales del navegador
